# NC Elektric — Design Implementation Kit

This package is designed to be copied **as a single folder into the root of your existing NC Elektric React project**. It is an **asset and design reference kit**, not a replacement application.

## Use
1. Extract ZIP. Copy folder `NC_Elektric_Design_Implementation_Kit` into the project root (beside `src`, `public`, and `package.json`).
2. Ensure your existing product photos and source code remain in place.
3. Open the project in Cursor Agent and paste `instructions/PASTE_IN_CURSOR.md`.
4. Cursor should copy `public/assets/` from the kit into the app's `public/assets/`, use the 3 reference screenshots for visual comparison, and preserve original product photography.

## Contents
- `design-references/`: the three recovered original approved page mockups (screenshots are NOT finished assets)
- `public/assets/brand/`: newly redrawn scalable NC Elektric logo variations and favicon
- `public/assets/banners/`: high-res scalable industrial vector hero and collection banners; approximate composition of the approved mockups
- `public/assets/categories/`: separate high-res scalable category illustrations (not original product photography)
- `public/assets/products/`: explicit note for six existing original photos; NOT included because original bytes were not recoverable in this workspace
- `instructions/ASSET-MAP.json`: exact paths and intended image placements
- `instructions/PASTE_IN_CURSOR.md`: complete agent prompt

## Accuracy and caution
This kit recreates the approved *style*, not exact original raster hero photographs. The recovered mockup screenshots include obsolete shopping carts and unverified prices and specifications; do not copy those cues or statements into the B2B quotation website. These artwork files are representative industrial illustrations and should not be represented as real photographed inventory. This is not a complete independently tested application build.
